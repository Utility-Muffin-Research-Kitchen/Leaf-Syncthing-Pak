# Syncthing compatibility notice v0.0.1

This inert Pak keeps Syncthing visible in Pak Rat on older Leaf versions without
installing or starting a background service.

Open it to see that the full Syncthing Pak requires Leaf 0.10.0 or newer. Update
Leaf, uninstall this notice if it was installed on the Secondary card, then install
the full Pak on the Primary card.

This compatibility notice does not include Syncthing, open network connections,
or write Syncthing configuration or data.
